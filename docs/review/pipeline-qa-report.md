## 1. 产品结论（是否 OK）

| 维度 | 结论 | 说明 |
|------|------|------|
| **内部 MVP / 演示** | ⚠️ 基本可用 | 模板部署 → Argo 跑通；监控页 DAG/时间线可用 |
| **对外产品 / 生产** | ❌ 尚未 OK | 画布直部署失败、缺日志/加载模板、信息架构仍混、DAG 契约未闭合 |
| **UI 视觉** | ✅ 达标 | 三栏编辑器、分段 Tab、部署弹窗、表格列表风格统一 |
| **UX 闭环** | ⚠️ 半成品 | 主路径「设计→保存→模板运行→看 Argo」可走；「设计→直部署→排障」断裂 |

**一句话**：架构方向对，**监控侧（流水线运行）比编辑侧（流水线）更成熟**；编辑侧要先修 P0 再谈产品发布。

## 3. 缺陷清单（按优先级）

### P0 — 阻塞主路径

| ID | 问题 | 复现 | 建议 |
|----|------|------|------|
| **B1** | 画布「部署」未保存模板时 PG FK 失败 | 画布 1+ 节点 → 部署 → 确认 | `template_id` 空串改 `NULL`；或 deploy 前自动 save template |
| **B2** | 导出 JSON 不符合 transpiler 契约 | 导出见无 inputs/outputs、边非 port 格式 | 实施 `pipeline-frontend-guide.md` Phase A |

### P1 — 产品/UX 缺口

| ID | 问题 | 建议 |
|----|------|------|
| **U1** | 三处「运行记录」：算法运行记录 / 部署 Tab 标题 / Workflow 列表标题 | 统一命名：部署记录、Argo 工作流、算法运行 |
| **U2** | 无法从模板加载到画布 | 模板卡片加「编辑」→ `GET /pipelines/:id` 灌画布 |
| **U3** | 部署 Tab 运行历史无跳转 Workflow | 加链接 `/workflows/{workflowName}` |
| **U4** | 画布部署无选 asset | 与模板部署共用资产 Modal |
| **U5** | Workflow 详情无日志 | 接 `workflowApi.getLogs` + 侧栏 Tab |
| **U6** | 清空无确认 | `Modal.confirm` |
| **U7** | Workflow 列表无分页/筛选 | 按 status/时间筛选 + 分页 |

### P2 — 体验打磨

| ID | 问题 | 建议 |
|----|------|------|
| **U8** | 空画布无引导 | 中央提示拖组件 |
| **U9** | 组件库文案「请在 Registry 中添加」 | 改为「请在组件 Tab 新建」 |
| **U10** | 连线对小屏/新手不友好 | 端口 label 或连线成功 toast |
| **U11** | 导出 JSON 挡在画布底部 | 改 Drawer/Modal |
| **U12** | 组件未接 API / 无团队共享 | Phase B 接 `/components` |

## 4. 用户旅程验证

### 旅程 A：算法工程师「编排并跑通」（目标路径）

```
注册组件 → 拖画布 → 连线 → 保存模板 → 部署 Tab 运行 → 流水线运行 看状态
```

| 步骤 | 状态 |
|------|------|
| 注册组件 | ✅ |
| 拖画布 | ✅ |
| 连线 | ⚠️ 未验证数据传递 |
| 保存模板 | ✅ |
| 模板运行 | ✅ |
| Argo 监控 | ✅（无日志） |

**结论**：**可走通**，缺日志与连线契约。

### 旅程 B：「画完立刻部署」（常见预期）

```
拖画布 → 点部署
```

| 步骤 | 状态 |
|------|------|
| 部署 | ❌ FK 错误 |

**结论**：**断裂** — 必须已知「先保存再走部署 Tab」。

### 旅程 C：「排障失败任务」

```
流水线运行 → 点 Failed → 看节点 → 看日志
```

| 步骤 | 状态 |
|------|------|
| 列表/详情 | ✅ |
| 日志 | ❌ |

**结论**：只能看状态，**不能完成排障闭环**。

## 5. UI / UX 专项点评

### 5.1 做得好的

- **分段 Tab（画布/组件/部署）** 比旧版 Ant Tabs 更贴任务流。
- **部署弹窗** 有说明、节点/边统计、空图禁用部署 — 专业。
- **模板部署 + 资产 Modal** 文案清楚（可不选资产）。
- **Workflow 详情** DAG + 时间线双视图，节点侧栏信息完整。
- **侧栏**「流水线」与「流水线运行」分离 — 方向正确。

### 5.2 仍别扭的

| 问题 | 用户感受 |
|------|----------|
| 两个「运行记录」列表 | 「我提交的」和「集群里所有 Workflow」分不清 |
| 部署 Tab 也叫「运行记录」 | 以为是 Workflow 列表 |
| 模板不能加载回画布 | 保存了只能跑，不能改 |
| JSON 导出占底部 | 像调试面板，不像产品功能 |
| React Flow 水印 | 偏开发态 |

### 5.3 信息架构建议（产品）

```text
流水线 (/pipeline)
  ├─ 画布      — 设计 DAG
  ├─ 组件      — 镜像注册表（= 原 Registry 能力）
  └─ 部署记录  — 我保存的模板 + 我触发的 deployment（可跳转 Argo）

流水线运行 (/workflows)
  └─ 集群内全部 Argo Workflow（运维/排障视角）
```
