# Trash

What to do when important data is accidentally deleted?

Typical scenarios:

- Accidentally deleted important data, need to recover

- Need to view deleted data, understand deletion history

- Need to clean up unnecessary data, free storage space

- Need to follow data retention policies, regularly clean expired data

Trash is designed to solve these problems. By centrally displaying logically deleted data from all modules, supporting search, batch recovery and permanent deletion operations, it effectively avoids data loss from accidental deletion and provides administrators with a unified data recovery and cleanup management interface.
