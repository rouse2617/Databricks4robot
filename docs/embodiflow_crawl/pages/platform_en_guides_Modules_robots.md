# Robots

How to efficiently manage robot devices and monitor data collection status?

Typical scenarios:

- Need to view data collection status by robot model, understand data volume of each model

- Need to quickly jump to data list of a specific model, view detailed data

- Need to locate problem devices, discover and resolve issues in time

- Need to monitor device status, ensure data collection work proceeds smoothly

Robot management is designed to solve these problems. By aggregating data volume by robot model and quickly jumping to corresponding data lists, it helps administrators and project managers efficiently manage robot devices, monitor data collection status, and locate problem devices.
