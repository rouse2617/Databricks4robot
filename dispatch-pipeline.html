F · Webhook (O(1))

hot path
Argo 终态通知 → 1 个 CTE 推进 counter
handler.go → AdvanceItemForRun → AdvanceItemAndCountAtomic
  • 取消 SyncJob（O(N²) full-batch scan）
  • 1 个 CTE：先把 item 从非 terminal 推进，同时 bump job counter
  • WHERE status NOT IN ('completed','failed','cancelled') 守门：重复投递命中 0 row → counter 不动（idempotent）
  • 收 Argo webhook 立即 200；counter 自愈交 reconciler
WITH upd AS (
  UPDATE backfill_items
  SET status=$2, workflow_name=..., error_message=..., finished_at
  WHERE id=$1 AND status NOT IN (terminal)
  RETURNING job_id
)
UPDATE backfill_jobs
SET completed_count = completed_count + (case $2='completed'),
    failed_count    = failed_count    + (case $2 in failed|cancel),
    updated_at = now()
WHERE id IN (SELECT job_id FROM upd)

G · Watcher bulk

LIST + RV gate
一次 LIST 每个 namespace，按 RV 守门
backend/internal/usecase/pipeline/watcher_bulk.go
  • selector: workflows.argoproj.io/completed=false（Argo controller 在第一次 reconcile 时打的 label）
  • 每 (cluster, namespace) 一次 ListWorkflows；LIST 失败 → legacy 降级 per-run GET（bounded）
  • 命中 wf → applyWorkflowToRun，前提是 markWorkflowApplied(runID, resourceVersion) 通过
  • 缺席 wf（刚终态/未打 label）→ 残量 targeted GET（bounded）
  • recalibrateEvery=10：每 10 tick 强制 reapply 全部（RV gate 自愈）
回滚: WATCHER_MODE=legacy

H · Reconciler

self-heal
60s 一回兜底；counter 覆写自愈
backend/internal/usecase/backfill/usecase.go:StartJobReconciler
  • 60s tick 扫所有 non-terminal jobs
  • SummarizeItemStatuses 全 batch 聚合
  • UpdateJobProgress(comp, fail, status) 覆写 counter（drift 自愈）
  • 全 terminal → 翻 job 终态 + notifyJobTerminalIfNeeded（atomic claim）
  • webhook 丢事件 / race 在一分钟内收敛

Side-effect: pod 回收 (CYB-3667 主线)

成功 pod

PodGC.Strategy = OnWorkflowSuccess + DeleteDelayDuration = "24h"

  • Argo controller 立刻排队删除，但 24h 后才执行
  • 24h 内：kubectl logs / describe / GKE console 链接全可
  • 24h 后：pod 真没了 → /diagnostics 返 200 + {garbageCollected:true}，前端 "查看 Pod" 按钮仍渲染

失败 pod

无限保留（运维取证用）

  • 跟成功 pod 走不同分支
  • 没有 24h 计时，TTL 由 Workflow 对象自身（30 天）控制

回滚闸门

整套新机制都有 *_MODE=legacy 紧急回滚（每个 release 留一版本）:

  • BATCH_DISPATCH_MODE=legacy → 退回老 executeItem 路径
  • WATCHER_MODE=legacy → 退回 per-run rotating-window GET

关键不变量 (设计核心)

  • Submit 热路径 不包外层事务
  • Webhook 热路径 不batch scan
  • Watch 热路径用 resourceVersion gate 跳过未变更
  • 跨实例互斥由 PG session advisory lock 覆盖 per-cluster
  • 幂等性由 deterministic name + AlreadyExists + RV gate 兜底
  • 全部 fallback 由 60s reconciler 自愈
  • 每 10 个 watcher tick 强制 recalibrate 防止 gate 漂移
  • pod 24h 保留 + GC 后 stub 兜底
